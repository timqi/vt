把输出的 base64 与导出口令填入下方——解密只在本浏览器进行，mac_key 不上传。注册完成后本页即登录；请从正式域名打开本页，它将成为 WebAuthn origin。

每个挑战一行（pending / approved / rejected / expired）。「记录」列显示本次涉及记录的名称（服务端保存；客户端自报的名称标为「自报」，可在详情里点击重命名）。「缓存」列显示该次审批授予的 DEK 缓存时长；带有效缓存的行可在「操作」列单独清除。点击行查看命令、IP 等完整详情。保留 90 天。

时间状态主机记录缓存操作

当前真实存在的 DEK 缓存（按授予它的那次审批分组）。在有效期内，持有同一 VT_PASSKEY_TOKEN 且项目（git 公共目录，否则为工作目录）一致的调用者可免手机审批解密这些记录，所以此处的每一行都是一份仍然生效的授权。清除立即生效；延长必须经手机 Passkey 重新批准，每次延长把有效期重设为「批准时刻 + 所选时长」，可反复续期，但已过期的缓存无法续期——只能重新审批。

主机 · 项目记录条目 剩余 · 到期操作

每台主机经 vt enroll + 手机 Passkey 审批后获得自己的 VT_PASSKEY_TOKEN。令牌有效期 7 天，每次使用自动重设为「此刻 + 7 天」；到期或被吊销后该主机的解密请求会被拒绝，需重新 enroll。吊销立即生效，不需要 Passkey。此处不显示令牌密文（Worker 从不存储它）。令牌派生自 Worker 的根密钥：轮换 SECRET 不影响令牌，恢复出厂（重新引导）会让所有令牌失效，每台主机需重新 enroll。

会话

登录会话 8 小时后到期。「退出登录」只清除本浏览器的 cookie；「退出所有会话」使每个已登录设备立即失效（吊销 Passkey 也会如此）。

缓存与审批

设置保存在 Durable Object 的加密配置里，保存即生效。审批页始终提供缓存时长，默认「不缓存」即不写入；命中通知每次免审批解密都会推送，默认关闭。UV 策略只能提高审批的验证级别，格式见 docs/cf-worker-deploy.md；留空为默认（discouraged）。

SECRET

Worker 唯一的 Wrangler secret，只用来包裹根密钥；轮换不影响 Passkey、主机令牌、推送订阅与缓存。点击后新值只显示一次：执行 wrangler secret put SECRET 粘贴它。新旧两个值在此期间都有效，Worker 第一次以新值启动后旧值即作废。

新 SECRET

wrangler secret put SECRET，粘贴上面的值。关闭本页后无法再次查看；未及时部署可再次轮换。

推送

Web Push 直接送达本设备，无第三方。iOS 16.4+：Safari → 分享 → 添加到主屏幕，从图标打开本页再点「开启推送」；移除图标即停止推送。审批、enroll 与缓存命中（需开启上面的命中通知）都走这里。
