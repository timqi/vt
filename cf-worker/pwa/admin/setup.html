Passkey

管理 phone 审批 ceremony 用的 Passkey（CREDENTIALS_JSON）。首个 Passkey 的 master 必须等于 macOS mac_key；新增 / 吊销自动读取当前环境变量。生成后手动 wrangler secret put CREDENTIALS_JSON 并 deploy。

当前 Passkey

    从 macOS Master Key 引导

    浏览器无法独立完成这一步：master 必须取自 Mac keychain 的 mac_key。在 Mac 本机 执行（Touch ID 门控），按提示设置一个一次性导出口令：

    vt secret export

    把输出的 base64 与导出口令填入下方——解密只在本浏览器进行，mac_key 不上传。建议直接在 Mac 的浏览器里完成本页，避免跨设备复制。

    现有 CREDENTIALS_JSON

    自动读取自环境变量

    已从环境变量预填，通常无需改动；为空时可手动粘贴。

    ⚠️ 吊销 ≠ 密钥轮换：仅从允许列表移除，master_key 不变。若该 Passkey 的密文与 PRF 曾泄露，仍可离线解出同一 master_key。

    输出

    复制后执行 wrangler secret put CREDENTIALS_JSON 再 wrangler deploy 生效。
